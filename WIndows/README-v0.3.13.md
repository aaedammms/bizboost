# E-Inventory Pro v0.3.13 — E+ Branding

This version updates the app identity using the new blue E+ logo supplied by the owner.

- Replaces the in-app login and sidebar logo (`assets/app-logo.png`).
- Replaces the multi-resolution Windows app/installer icon (`build/icon.ico`).
- Keeps the product name **E-Inventory Pro** and the existing Windows application ID for update continuity.
- No changes to database schema, database location, roles, stock, sales, invoices, quotations or backup logic.

Build on Windows: `npm install`, `npm start`, then `npm run build`.

Installer: `release\E-Inventory-Pro-Setup-0.3.13.exe`.
