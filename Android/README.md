# BizBoost Android

BizBoost is an offline inventory and business management application.

## Version
- Version: 1.0.0
- Platform: Android
- Package ID: `com.bizboost.app`

## Features
- Inventory management
- Stock IN and OUT tracking
- Sales and checkout
- Quotations and invoices
- PDF generation and sharing
- User roles and permissions
- Analytics dashboard
- CSV export
- SQLite database backup and restore
- Audit log
- Offline operation

## Installation
1. Download the latest APK from the Releases section.
2. Open the APK on your Android device.
3. Allow installation from the selected source if prompted.
4. Install and launch BizBoost.
5. Register your Owner account.

## Important
BizBoost Android stores its data locally on the device. Back up your database regularly.
